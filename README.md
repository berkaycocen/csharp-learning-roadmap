# C#, OOP ve Veri Yapıları Çalışma Yol Haritası

Bu depo, C# temellerinden başlayarak Nesne Yönelimli Programlama (OOP) ve Veri Yapıları & Algoritmalar konularına uzanan uygulamalı yazılım geliştirme çalışmalarımı ve mini projelerimi içerir.

## 🎯 Çalışma Hedefleri
* C# sözdizimi, veri tipleri, tür dönüşümleri ve kontrol yapıları
* Nesne Yönelimli Programlama (Encapsulation, Inheritance, Polymorphism, Interface)
* Temel Veri Yapıları (Linked List, Stack, Queue, Tree, Hash Table) ve Algoritma Analizi

## 📂 Proje İçeriği
* **`Lesson1/`**: C# temelleri, veri tipleri, tür dönüşümleri ve *Spor Salonu Kayıt Sistemi* konsol uygulaması

## 🛠️ Kullanılan Teknolojiler
* **Dil:** C# (.NET)
* **IDE:** Visual Studio 2026
* **Sürüm Kontrolü:** Git & GitHub
